# Hotel-Performance-Bookings-Insights

## Overview
This project features a **Power BI dashboard** that provides insights into hotel bookings, occupancy trends, revenue, and cancellation patterns. It includes **Power Query transformations, DAX calculations, and interactive visualizations** for data-driven decision-making.

## Key Features
- **Total Revenue & Room Nights**: Aggregates revenue and booked nights.
- **Customer Loyalty Analysis**: Identifies repeat and non-loyal customers.
- **Booking Trends**: Tracks single vs. multi-night stays, weekdays vs. weekends.
- **Cancellation Insights**: Measures cancellation rates and patterns.
- **Dynamic Visualizations**: Includes slicers, drill-throughs, and KPIs.

## Files
- `Hotel Bookings Dashboard.pbix` - Main Power BI dashboard.
  
## How to Use
1. Open `Hotel Bookings Dashboard.pbix` in Power BI.
2. Use slicers to filter by date.
3. Analyze key performance metrics to make data-driven decisions.

## Technologies Used
- **Power BI** (Data visualization)
- **DAX** (Custom measures and calculations)
- **Power Query** (Data transformation)
